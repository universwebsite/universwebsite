## Локальный ИИ-контур (On-Premise AI-Ops без GPU)

Развёртывание и оптимизация автономного ИИ-ассистента в закрытом периметре — без обращения к внешним облачным API.

* **Движок инференса (Ollama):** установлен нативно на Bare-Metal хост (Intel Core i5-13400, CPU-only). Перенос из LXC снял ограничение планировщика `cgroups v2`, которое резало CPU-время раннера llama.cpp — именно оно душило генерацию. Веса моделей вынесены в изолированный ZFS-датасет.
* **Интерфейс и Strict RAG (Open WebUI):** развёрнут в Docker Compose v2 с разделением прав доступа (RBAC) и подходом **Prompts-as-Code** — конфигурации `Modelfile` хранятся в репозитории.
* **Двухконтурная архитектура:**
  * *Приватный контур* — работа с закрытой технической документацией, регламентами и инфраструктурными runbook'ами предприятия.
  * *Публичный демо-контур* — изолированный консультант на облегчённой модели: вшитые границы компетенций, полный запрет доступа к приватным коллекциям знаний.
* **Управление резидентностью моделей:** `OLLAMA_KEEP_ALIVE` и `OLLAMA_MAX_LOADED_MODELS` в systemd-юните — осознанный компромисс между мгновенным ответом и объёмом памяти: резидентный раннер Qwen2.5:14B держит в RAM до ~17 ГиБ, поэтому число одновременно загруженных моделей ограничивается политикой, а не оставляется «как получилось».

### Замеры Qwen2.5:14B (Q4, CPU-only, без GPU)

| Метрика | До (Ollama в LXC) | После (Bare-Metal) |
| :--- | :--- | :--- |
| **Скорость генерации (`eval rate`)** | `0.25 tok/s` | **`~6.45 tok/s` (рост в 25 раз)** |
| **Время до первого токена** | Десятки секунд (холодный старт — загрузка весов с NVMe) | Мгновенно (модель резидентна в RAM) |
| **Планирование потоков CPU** | Квантование `cgroups v2` | Нативный доступ к P-ядрам |

Методика замеров: `ollama run --verbose` и `llama-bench`, фиксированная длина промпта и генерации. Итоговая скорость соответствует пределу пропускной способности двухканальной DDR5 для модели такого размера — инференс на CPU ограничен памятью, а не процессором, поэтому дальнейший прирост даёт только память (каналы/частота), а не CPU.

## Технологический стек и экспертиза

* **Виртуализация и СХД:** отказоустойчивые кластеры **Proxmox VE 9** (Corosync Mesh, внешний арбитр `corosync-qnetd`), **ZFS** на NVMe с инкрементальной репликацией (`pvesr`).
* **AI-Ops и локальные LLM:** оптимизация **Ollama + Open WebUI (Strict RAG)** на Bare-Metal CPU-only, Prompts-as-Code (`Modelfile`), управление резидентностью моделей.
* **Infrastructure as Code:** декларативное управление **Terraform**, автоматизация **Ansible**, оркестрация **Docker Compose v2** и LXC.
* **Сети и безопасность:** изолированные 10G-магистрали, IGMP-мультикаст, диагностика (`tcpdump`, `arping`, `mtr`), защищённые туннели (WireGuard, Cloudflare Tunnels).
* **Бэкенд и Docs-as-Code:** веб-платформы на **PHP 8 / Symfony 7** (Nginx, PHP-FPM), Python, SQL; документация в Markdown с автоматической публикацией через **MkDocs**.

Комплекс круглосуточного ТВ/радиовещания: перехват сырых MPEG-TS (UDP Multicast) потоков фоновыми контейнерами FFmpeg без транскодирования (`-c copy`), раздача через медиасервер **SRS** (WebRTC с задержкой менее 1 с / HLS), веб-платформа на **Symfony 7**. Многоконтейнерный контур автоматической генерации видеопрезентаций: детекция лиц (`InsightFace`, `YOLOv8-n`), генерация сценариев локальными LLM, индексация сцен через `Qdrant` (CLIP), генерация кадров (`SDXL Turbo`), синтез речи (`Piper TTS`) и сборка через `FFmpeg` / **Symfony 7**.
