### Локальный ИИ-контур (On-Premise AI-Ops без GPU)

Развёртывание и оптимизация автономного ИИ-ассистента в закрытом периметре без обращения к внешним облачным API.

* **Движок инференса (Ollama):** Установлен нативно на Bare-Metal хост (CPU Intel Core i5-13400) в обход ограничений планировщика cgroups v2 в непривилегированных LXC-контейнерах. Веса моделей вынесены в изолированный ZFS-датасет.
* **Интерфейс и Strict RAG (Open WebUI):** Развёрнут в Docker Compose v2 с жёстким разделением прав доступа (RBAC) и подходом **Prompts-as-Code** (`Modelfile` в репозитории).
* **Двухконтурная архитектура:**
  * *Приватный контур:* Работа с закрытой технической документацией, регламентами и инфраструктурными runbook'ами.
  * *Публичный демо-контур:* Изолированный консультант на базе облегчённой модели с вшитыми границами компетенций и полным запретом доступа к приватным коллекциям знаний.

| Метрика стенда (`Qwen2.5:14B`) | До (внутри LXC) | После (Bare-Metal + тюнинг) |
| :--- | :--- | :--- |
| **Скорость генерации (`eval rate`)** | `0.25 tokens/s` | **`~6.45 tokens/s` (рост в 25 раз)** |
| **Холодный старт из RAM (`KEEP_ALIVE=-1`)** | `> 1000 мс` | **`< 1 мс` (`~458 µs`)** |
| **Планирование потоков CPU** | Квантование `cgroups v2` | Нативный доступ к P-ядрам |
| **Зависимость от GPU и облаков** | Требуется GPU / API | **0 ₽ на GPU, 100% On-Premise** |

## 🛠 Технологический стек и Экспертиза

* **Виртуализация и СХД:** Отказоустойчивые кластеры **Proxmox VE 9** (Corosync Mesh, внешний арбитр `corosync-qnetd`, восстановление кворума `< 5 сек`), распределенные СХД **Ceph** и **ZFS** (NVMe-пулы, инкрементальная репликация `pvesr`).
* **AI-Ops & Локальные LLM:** Оптимизация **Ollama (`Qwen2.5:14B`, `~6,45 tok/s` на CPU Intel Core i5-13400 без GPU) + Open WebUI (Strict RAG)** на Bare-Metal с тюнингом потоков (`OLLAMA_NUM_THREADS=1`) и удержанием весов в памяти (`KEEP_ALIVE=-1`, холодный старт из RAM `< 1 мс`).
* **Infrastructure as Code (IaC):** Декларативное управление через **Terraform** (провайдер `bpg/proxmox`, IaC-импорт существующих ZFS-томов), автоматизация на **Ansible**, оркестрация **Docker Compose v2** и LXC.
* **Сети и Безопасность:** Изолированные 10G-магистрали, IGMP-мультикаст, диагностика (`tcpdump`, `arping`, `mtr`) и защищенные туннели (Cloudflare Tunnels, WireGuard).
* **Бэкенд и Docs-as-Code:** Разработка веб-платформ на **PHP 8 / Symfony 7** (Nginx, PHP-FPM) и ведение документации в Markdown с автоматической публикацией через **MkDocs** на [mediahard.ru/wiki](https://mediahard.ru).

## 🎬 Реализованные проекты в Продакшене

### 1. АПК «МедиаКластер» 
Комплекс круглосуточного ТВ/радиовещания с локальным ассистентом на **Qwen2.5:14B** с RAG по базе знаний кластера для диагностики логов, генерации IaC-конфигураций и работы с runbook'ами. Включает перехват сырых MPEG-TS (UDP Multicast) потоков через фоновые контейнеры FFmpeg без транскодирования (`-c:v copy`), раздачу в медиасервер **SRS** (WebRTC `< 1 сек` / HLS) и веб-платформу на **Symfony 7**.

### 2. Распределенный ИИ-конвейер (mediahard.ru)
Многоконтейнерный контур для автоматической генерации видеопрезентаций, включающий детекцию лиц (`InsightFace`, `YOLOv8-n`), генерацию сценариев через локальные LLM, индексацию сцен через `Qdrant` (`CLIP ViT-B/32`), генерацию кадров через `SDXL Turbo`, синтез речи (`Piper TTS`) и сборку через `FFmpeg` / `Symfony 7`.
